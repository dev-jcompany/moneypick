# 01. ROADMAP

> 전체 개발 일정과 Release/Sprint별 목표를 관리한다.

## Release 개요

### Release 0.1 — MVP (현재)

- Next.js 기반 프론트엔드 페이지 구현 (홈, 카테고리, 포스트, 계산기, 검색, 뉴스, 문의 등)
- 관리자(Admin) 화면 UI 구현 (콘텐츠/공지/카테고리/태그/구독자/뉴스레터/미디어/사용자/설정/계산기 관리)
- Mock 데이터(`src/data/*.ts`) 기반 동작
- 프로젝트 운영 체계(AI-POS) 도입

### Release 0.2 — 데이터/백엔드 연동 (예정)

- 실 데이터 소스(DB 또는 Headless CMS) 연동
- 관리자 화면 CRUD를 실 데이터에 연결
- 인증/권한 체계 도입 (관리자 로그인)

### Release 0.3 — 운영 준비 (예정)

- 뉴스레터/구독자 발송 파이프라인
- SEO/사이트맵/robots 점검 및 개선
- 배포 자동화(CI/CD) 구성

### Release 1.0 — 정식 오픈 (예정)

- 실 운영 환경 배포
- 모니터링/로깅 체계
- 접근성/반응형 QA 완료
